# TrojanTutor v0.10 — Roadmap Weeks 2–3 (Nov 16–29, 2026)

This release completes the two roadmap weeks after the vertical slice:
**Week 2, conversation quality** (streaming, equations, session context, chat UI) and **Week 3,
course grounding** (PDF ingestion, chunks/embeddings, sources, retrieval tests, permission
boundaries). It also closes a Week 1 gap: earlier docs said an optional LLM path existed, but
there was no LLM code in the repository. There is now one. It is off by default and constrained
to the slides.

## Evaluation (draft labels; engineering checks, not research results)

Retrieval, 65 queries, unit filter on, 143 chunks:

| mode | R@1 | R@3 | R@5 | MRR@10 | nDCG@5 |
|---|---|---|---|---|---|
| bm25 | 0.692 | 0.892 | 0.954 | 0.802 | 0.814 |
| dense (LSA) | 0.646 | 0.892 | 0.938 | 0.770 | 0.780 |
| hybrid (RRF) | 0.662 | 0.908 | 0.954 | 0.787 | 0.803 |

**Finding:** on a 143-chunk lecture corpus, local embeddings do *not* beat BM25 (hybrid ties at
R@5 and is slightly worse at R@1). The tutor therefore keeps BM25 as its default. Embeddings stay
available for comparison and for larger corpora, where the conclusion may change.

Concept resolution (which lesson the tutor teaches):

| set | result | note |
|---|---|---|
| dev (60 student-style questions) | 0.933 top-1 (was 0.867 at the start of this release) | **used while tuning** the matcher; optimistic |
| held-out: 28 covered assignment exercises | **0.714** top-1 | labels fixed before evaluation, not tuned on |
| held-out: 9 exercises on topics with no lecture deck | 0.889 correctly declined | Tutte–Berge, blossom, Christofides, … |
| homework guard | 0.917 recall on 48 exercises; **0** false positives on 125 ordinary questions | IDF-weighted overlap |

The dev/held-out gap (0.93 vs 0.71) is the honest generalization picture. Long, formal exercise
statements are harder than short student questions. Fixing that is a Week 4+ task, and the
held-out set should then be replaced by questions from real students (with consent).

## Choices worth knowing

- **pdftotext over pypdf for slides.** pypdf scored one query better at R@5 (0.969 vs 0.954) but
  glued words in quoted evidence ("letP", "theneach"). Students read the excerpts, so readability
  won. Both paths are in `app/ingest.py`.
- **No React/Vite yet.** The roadmap's Week 1 named React/Vite. The UI is still one dependency-free
  HTML file so the project runs with `pip install` alone. Porting is mechanical once the API is
  stable, which it now is.
- **The LLM is never the source of truth.** It sees only the resolved lesson card and numbered
  slide excerpts, uses verified algorithm narration verbatim, and is bypassed entirely for homework
  and uncovered topics. Any provider error falls back to the card engine.

## Enabling the grounded LLM engine (optional)

```bash
export TROJANTUTOR_LLM=anthropic ANTHROPIC_API_KEY=...        # model defaults to claude-sonnet-5-5
# or: export TROJANTUTOR_LLM=openai OPENAI_API_KEY=... TROJANTUTOR_LLM_MODEL=<model>
# or an OpenAI-compatible local server: TROJANTUTOR_LLM=openai TROJANTUTOR_LLM_BASE_URL=http://localhost:11434/v1 TROJANTUTOR_LLM_MODEL=<model>
python -m uvicorn app.main:app --reload
```
The UI's engine menu then enables "Grounded LLM". The live provider path has not been run in this
environment (no network). It is covered by tests with recorded-format fake streams for both
providers, so expect to verify it once with your key.

## Known limitations

- Gold labels are drafts written from the slides; **a TA should review them** before any number is reported.
- 4 slide tokens are still glued (e.g. "alsorecognize") because their parts never appear separately.
- Figure-only slides and assignment figures are not readable; figure-dependent exercises are flagged and not posed as practice.
- The rule-based Misconception Lab still covers only Kruskal-cycle and Dijkstra-negative-cost reasoning.
- No course material is instructor-approved yet. Request written permission before any shared deployment or study.
