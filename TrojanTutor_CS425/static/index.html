Current baseline and limits

The tutor retrieves from 28 authored concept lessons and the lecture slides (animation frames merged), and narrates algorithm demos from tested code. It requires no API key. It includes limited rule-based feedback on selected misconception patterns, but cannot reliably grade arbitrary answers. It does not use a generative language model; every sentence is authored lesson text, narrated code output, or a slide excerpt. Voice recognition and speech synthesis are browser features; microphone audio is not uploaded directly to this FastAPI server, but browser recognition services may process speech. Instructor permission is required before redistribution or research study use.
